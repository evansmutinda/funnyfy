  SIMPLE INSTRUCTIONS - CREATE ADMIN USER
═══════════════════════════════════════════════════════════════

STEP 1: GET YOUR USER ID
───────────────────────────────────────────────────────────────

Option A: Browser (Easiest)
────────────────────────────
1. Open Chrome or any browser
2. Press F12
3. Click "Console" tab
4. Paste this code and press Enter:

fetch('https://funnyfyapp.vercel.app/api/admin/create-admin-user', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: '{}'
})
.then(r => r.json())
.then(data => {
  alert('Your User ID: ' + data.userId);
  navigator.clipboard.writeText(data.userId);
});

5. A popup will show your User ID - COPY IT!


Option B: PowerShell (If browser doesn't work)
───────────────────────────────────────────────
1. Press Windows Key + X
2. Click "Windows PowerShell"
3. Paste this and press Enter:

$r = Invoke-RestMethod -Uri "https://funnyfyapp.vercel.app/api/admin/create-admin-user" -Method POST -ContentType "application/json" -Body '{}'; Write-Host "User ID: $($r.userId)"; $r.userId | Set-Clipboard

4. Copy the User ID that appears


STEP 2: ADD TO VERCEL
───────────────────────────────────────────────────────────────
1. Go to: https://vercel.com/dashboard
2. Click your project
3. Click "Settings" (top menu)
4. Click "Environment Variables" (left sidebar)
5. Click "Add New"
6. Key: ADMIN_USER_IDS
7. Value: (paste your User ID)
8. Check all: Production, Preview, Development
9. Click "Save"
10. Click "Redeploy"


STEP 3: LOGIN
───────────────────────────────────────────────────────────────
1. Go to: https://funnyfyapp.vercel.app/admin/login
2. Enter your User ID
3. Click "Sign in"
4. Done! 🎉
